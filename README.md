# VARETHIA — The World of a Thousand Elements

A dark-medieval fantasy simulation concept and browser prototype.

## Visual direction
- **Global style:** 2.5D presentation with layered parallax, sprite/rig-based characters and effects.
- **Architecture exception:** buildings, castles, towers, bridges, interiors and dungeons are fully 3D assets.
- **HUD:** dark medieval, full RPG.
- **Difficulty target:** brutal realism.
- **Campaign state:** not started; character creation is the first entry point.

## Included
- Animated main menu and title reveal.
- Character-creation entry screen (does not start the campaign).
- Full RPG HUD mockup: health, magic, calendar, relationships, injuries and world events.
- Parallax atmosphere, embers, fog, lightning, rune and button feedback effects.
- World bible documenting elements, curses, spellcasting, NPC autonomy, factions, consequences and calendar.
- Data-driven prototype examples for NPCs and world events.

## Run
Open `index.html` in a browser, or serve this directory with any static web server.

## Important prototype boundary
This is a front-end prototype and design foundation, not a finished 3D game engine. The scene uses CSS layers and UI animation to preview the 2.5D mood. Actual 3D building meshes, animated character rigs, combat simulation, persistence, procedural world simulation and production VFX/audio still require a game engine and assets.

## Calendar
Varethian day: 30 hours. Week: 8 days. Month: 40 days. Year: 12 months / 480 days.
Months: Ashfall, Frostveil, Thornrise, Emberwake, Duskmere, Stormcall, Bloodmoon, Suncrest, Hollowtide, Ironreach, Starfall, Nightveil.

## Start policy
The startup button opens character creation only. The simulation clock and campaign remain paused until a player explicitly confirms entry into the world.
